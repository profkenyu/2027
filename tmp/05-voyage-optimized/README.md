# A WORLD, STILL UNKNOWN.

김건우 제20회 개인전 **BEYOND THE KNOWN — A TERRAFORMING PROJECT**의 관객 참여형 탐사 작품입니다.

`index.html`을 Safari 또는 Chrome에서 여십시오. 필요한 파일을 모두 이 폴더에 포함했으므로 인터넷 연결과 별도 설치가 필요하지 않습니다. Mac 전시장에서는 `전시시작.command`를 더블클릭하면 Chrome 전용 프로필과 전체 화면으로 실행하고 화면 절전을 방지합니다. Google Chrome은 미리 설치해야 하며, 종료는 Command + Q입니다.

## 전시장 운영

- 행성 선택 → 1인칭 로버 탐사 → 탐사 기록 → 30초 후 행성 선택으로 복귀합니다.
- 상단 BEYOND THE KNOWN은 파일 경로에 의존하지 않는 홈 버튼입니다. 탐사 중 누르면 현재 경로를 기록한 뒤 행성 선택으로 돌아갑니다. 폴더를 다른 위치에 옮기거나 단독으로 복사해도 홈 기능이 유지됩니다.
- 탐사 카메라는 지면에서 약 1.42 m 높이의 로버 광학 마스트에 고정됩니다. 외부 로버, 추적 카메라, 자유 비행 시점은 없습니다.
- 방향키 또는 WASD: 전진·후진·좌우 조향. SPACE: 정지 후 6초간 측정. 이동·조향을 재개하면 측정이 취소되며 이미 사용한 에너지는 반환되지 않습니다.
- 화면 드래그: 마스트 시선 조정. 좌우 ±66°, 상하 제한이 있으며 카메라 위치는 이동하지 않습니다. 화면 더블클릭으로 시선을 전방에 맞춥니다.
- LIGHT: 전방 보조광, 소비전력 9 W. SOUND: 로버 내부 기계 진동과 짧은 측정 통신음. 기본은 무음이며 관객이 켤 때만 시작됩니다.
- ESC: 일시 정지·계속. 다른 창이나 탭으로 전환하면 탐사와 에너지 계산을 일시 정지합니다. 복귀 후 ‘탐사 계속하기’를 누릅니다.
- 배터리 소진, 관객의 종료, 가상의 6분 통신 창 종료로 기록 화면에 진입합니다. 조작 없이 120초가 지나면 기록을 마치고 초기화합니다. 실제 체험 시간은 경로·측정 횟수에 따라 달라집니다.
- 같은 브라우저·주소에서 완료된 최근 18회 탐사를 보관합니다. 지도에는 관측 경로 주변과 측정한 지점만 나타납니다. 저장이 차단되거나 용량이 부족하면 현재 실행 중에만 보관하고 화면에 이를 표시합니다. 브라우저 데이터 삭제 시 기록도 삭제됩니다. 여러 기기 사이에 동기화되지 않습니다.
- 전시장에서는 동일한 브라우저와 고정 주소로 운영하십시오. `file://`의 저장 지속성은 브라우저 설정에 따라 다르므로 기록 보존이 중요할 경우 고정된 로컬 HTTP 주소로 운영하는 편이 좋습니다.
- 화면 우측 상단에서 전체 화면으로 전환할 수 있습니다. 모바일에는 터치 이동 버튼이 나타납니다. 링크·이동 버튼에는 장식용 화살표를 사용하지 않습니다. 로버 조작 방향 표시는 유지합니다.
- 전시 실행 명령 파일은 해당 파일이 들어 있는 폴더를 기준으로 시작합니다. 이름에 공백·한글·특수문자가 있는 경로도 파일 URL로 변환합니다. 별도 원본 폴더나 웹서버는 필요하지 않습니다.
- 탐사 기록은 브라우저에 저장되므로 파일 위치나 Chrome 프로필을 바꿀 때 이전 기록의 자동 이전을 보장하지 않습니다. 중요한 기록을 가진 운영 폴더는 위치를 고정해 사용하십시오.

## 시각·시간 설계

세 행성은 빙판의 균열, 분화구를 포함한 건조 분지, 시야가 짧은 대기권의 지형으로 구분됩니다. 넓은 빈 하늘과 지평선, 낮은 관측 시점, 느린 이동, 최소한의 계측 화면을 사용합니다. 빛과 지형은 이동 경로와 에너지 수지에 영향을 줍니다. 정지한 시간에도 기기 운영 에너지가 필요합니다.

입력 → 결정적 지형 높이장·태양 입사 모델 → 이동·충돌·에너지 적분 → 로버 마스트 위치 → 느린 기울기·광량 변화 → WebGL 지표·계측·노출 지도 → 경로 선택·정지 측정으로 구성됩니다.

## 과학적 구분

**물리적 원리**: 발전은 입사광·대기 투과·지형 차폐에 영향을 받습니다. 상승 이동에는 중력에 맞서는 일이 필요하며 기기·측정·조명은 전력을 사용합니다. 에너지는 발전량에서 소비량을 빼 적분합니다.

**수치 근사**:

```text
P_solar = 160 W × sin(태양 고도) × 대기 투과율 × 지형 노출률
P_drive = 120 kg × g × v × (0.02 + 양의 경사율) / 0.65
E_next = clamp(E + (P_solar − P_load) × dt / 3600, 0, 5 Wh)
```

높이장은 매끄러운 다중 스케일 지형 함수이며, 실제 관측 자료를 재구성한 지형이 아닙니다. 지형 차폐는 태양 방향 16개 표본으로 근사합니다. 확산광·먼지 축적·온도에 따른 배터리 효율·패널 기울기·바퀴 동역학·전자기 통신은 완전한 물리 계산에 포함하지 않았습니다. 카메라의 지면 높이와 차량 주행 판단은 동일한 높이장을 사용하지만, GPU 지표는 품질 단계별 삼각형 보간이므로 표면 위치에 작은 차이가 있을 수 있습니다. 마스트의 기울기와 진동, 전조등 광속 분포는 시각적 근사입니다.

**예술적 설정**: 세 행성, 중력·대기압·온도·방사선 수치, 초기 배터리 5 Wh, 6분의 통신 창, 짧은 시간 안에 낮아지는 태양은 가상의 전시 설정입니다. 측정값은 이 가상 모델에서 생성되며 실제 행성의 측정이나 탐사 예측을 의미하지 않습니다. 중력 값은 행성마다 일정합니다. 화면의 ‘미관측’은 실제 탐사 지역 분류가 아니라 관객이 아직 방문하거나 측정하지 않은 영역입니다.

물리 원리 확인에 사용한 1차 자료:

- NASA, [On Mars, Light Is Energy](https://science.nasa.gov/resource/on-mars-light-is-energy/)
- NASA, [Power Operations of the Mars Exploration Rovers](https://ntrs.nasa.gov/citations/20230007029)

## 파일과 품질

- `model.js`: 지형·조도·운동·에너지·측정·기록 검증.
- `renderer.js`: 행성 선택 화면, 지형·재질·대기·로버 1인칭 카메라.
- `atlas.js`: 행성별 지형 지도 캐시·관측 영역 마스크·탐사 경로 합성.
- `voyage.js`: 입력·상태 전환·계측·저장·사운드·전시장 초기화.
- `voyage.css`: 화면·반응형 조작계.
- `vendor/three.local.js`: 기존 프로젝트에 포함된 Three.js r185의 렌더러 부분을 별도 추출. 원래 작품의 동작 코드는 포함하지 않습니다. MIT 라이선스는 `vendor/LICENSE.txt`를 참고하십시오.

`?quality=high`, `?quality=mid`, `?quality=low`로 고정 품질을 지정합니다. 미지정 시 기기 특성에 따라 선택하고, 지속적인 프레임 지연이 발생하면 현재 장면의 지형 분할·해상도·그림자를 함께 낮춥니다. 매우 낮은 프레임에서도 감지가 작동하며, MID의 45fps 목표가 60Hz 화면에서 30fps로 떨어지던 타이밍을 수정했습니다. HIGH/MID/LOW 지형 분할은 320/224/144, 픽셀 비율 상한은 1.55/1.1/0.8, 목표 프레임은 60/45/30입니다. 화면 버퍼는 약 390만 픽셀로 제한하여 4K·5K 화면에서도 비용을 제한합니다. 실제 전시장 아이맥의 성능과 발열은 현장 확인이 필요합니다.

`?inspect`를 추가하면 개발자 콘솔의 `voyageInspect()`로 현재 상태를 읽을 수 있습니다. 방문객 화면에는 검사 버튼이 나타나지 않습니다.

## 검증 범위

이 폴더에서 `node --test tests/*.test.cjs`로 검증합니다. 기존 12개 항목과 이동 경로·홈 복귀·지도 캐시·품질 저하·프레임 타이밍·예외 복구 회귀 검증을 포함합니다. 결정적 지형·에너지 수지·측정 취소·종료 조건·기록 검증과 세 행성의 입력 및 화면 상태 전환을 확인합니다. 런타임 검증은 실제 Three.js의 지오메트리·행렬·셰이더 소스를 사용하되 GPU와 DOM을 대체한 환경에서 실행합니다. 카메라가 모든 품질 단계에서 지형 아래로 들어가지 않는지와 셰이더 소스의 연결도 확인합니다. 지도는 행성별로 65,536개의 높이 표본을 한 번 계산해 재사용하고, 관측하지 않은 지역은 표시하지 않습니다. 같은 행성에서 이동·대기·기록 화면으로 전환해도 높이를 다시 계산하지 않습니다.

제작 환경의 실행 제한으로 실제 브라우저의 GPU 셰이더 컴파일, 화면 캡처, 아이맥의 프레임·발열·장시간 운영은 확인하지 못했습니다. 최종 전시 설치 시 세 행성의 빛·가독성·조작감과 고정 브라우저 주소에서의 기록 보존을 현장에서 확인하십시오.
