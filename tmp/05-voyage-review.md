# 05-voyage 이동 점검 및 최적화

수정 대상의 현재 위치: `/Users/kenyu/Desktop/20th_codex/exhibition/05-voyage`.

이 폴더는 현재 작업공간의 쓰기 허용 범위 밖에 있으므로 직접 변경하지 않았습니다. 수정·검증한 교체용 폴더와 ZIP은 허용된 작업공간 안에 준비했습니다. ZIP의 최상위 폴더명은 `05-voyage`입니다.

| 항목 | 확인 결과와 수정 |
| --- | --- |
| 이동 후 홈 링크 | `../../index.html`이 존재하지 않는 상위 파일을 가리켰습니다. 내부 홈 버튼으로 변경하여 현재 경로를 저장하고 행성 선택으로 돌아가게 했습니다. |
| 장식 화살표 | 링크·이동 버튼의 장식 화살표와 관련 CSS를 제거했습니다. 실제 방향 조작 표시는 유지했습니다. |
| 지도 CPU 사용 | 지도 갱신마다 높이를 계산하던 부분을 행성별 512×512 지형 비트맵으로 캐시합니다. 높이 표본 65,536개를 한 번 계산한 후 재사용합니다. 정지 시 같은 지도 프레임도 재합성하지 않습니다. |
| 품질 저하 감지 | 프레임 수 임계치 때문에 매우 낮은 프레임에서는 감지하지 못하던 문제를 지연 시간 비율로 변경했습니다. 5fps 모의 환경에서도 검증했습니다. |
| 실제 GPU 부담 | 품질 변경 시 현재 지형을 320→224→144 분할로 바꾸고 이전 지오메트리와 그림자 버퍼를 해제합니다. |
| MID 프레임 | 매번 마지막 시간을 현재 시각으로 덮어써 60Hz에서 목표 45fps가 30fps로 떨어지던 타이밍을 수정했습니다. |
| 예외 처리 | 셰이더 컴파일 실패와 비동기 전환 오류를 복구 안내로 연결했습니다. |
| 상태 복귀 | 행성 재선택 시 계측·성능 감지·경고 시간을 초기화합니다. 다음 관객은 무음으로 시작합니다. Command 키 조합이 주행에 영향을 주지 않습니다. |
| 이동 가능한 실행 | 폴더 기준으로 실행하는 `전시시작.command`를 추가했습니다. 파일 URL 인코딩과 Chrome 전용 프로필, 전체 화면 및 절전 방지를 포함합니다. |

자동 검증 **20개 통과**. 자바스크립트 구문, 내부 자산·DOM 연결, ZIP 무결성 및 실행 파일 권한을 확인했습니다. 실행 제한으로 실제 브라우저의 GPU 컴파일·실화면·장시간 운영은 확인하지 못했습니다. 프레임 테스트는 모의 60Hz/5fps 스케줄러를 사용하며 실기기 프레임 측정이 아닙니다.
