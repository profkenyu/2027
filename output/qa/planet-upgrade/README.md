# 행성 환경 · 비행 · 이주선 설계도 개정

2026-09-13. 실행 파일은 루트 `index.html` → `planet.html` → `ending.html`이다. 원본 모듈을 수정하고 `npm run build`로 배포 HTML을 재생성했다.

## 시각 구성과 시간

- 이주선: 실제 엔딩 함선의 선체·압력 모듈·방열판·추진부·서비스 구조를 분해 투상도로 분리한다. 측면과 평면은 조립 상태를 유지하고 투상 폭에 일치하는 전체 길이 치수선을 표시한다. 기존 3장 순서와 공개 시간은 유지한다.
- P01: 희박한 차가운 대기와 어두운 상층. 수직 상승을 낮은 측면에서 본다.
- P02: 기존 지형의 바람축(0.9906, 0.1366)에 대응하는 먼지층. 횡이동 접근, 7.2초 감속, 반대 측면의 낮은 관찰 위치.
- P03: 청회색의 맑은 대기. 높은 접근 위치에서 6.5초 동안 조기에 감속하고 착지에 가까워지며 화각이 51°에서 42°로 좁아진다.
- 현재 이야기에서 P01은 손상된 탐사선과 함께 시작하고, P01 출발 → P02 도착/출발 → P03 도착을 재생한다. 기존 시작과 엔딩의 서사는 유지한다. 세 행성 모두 비행 프로파일을 정의하고 이륙/하강 수학 검사를 수행했다.
- 우주: 궤도 타원과 별의 흰 선 궤적을 렌더링 경로에서 제거했다. 이동 중 15초에 걸쳐 별의 밝기만 출현·소멸한다. 별은 시선 회전에 반응하지만 우주선의 이동에 따라 확대되거나 흐르지 않는다. 별 사이의 검은 여백을 유지한다. 기존 최종 도착 사건은 유지한다.

## 과학과 해석

A. 대기 성분·입자 특성·광로 길이에 따라 하늘색이 달라지고, 먼 별의 병진 시차는 가까운 우주선에 비해 작다는 일반 원리를 사용한다. 대기별 색 변화의 관측 참고: [NASA — Sunsets on Other Worlds](https://www.nasa.gov/solar-system/nasa-scientist-simulates-sunsets-on-other-worlds/).

B. 공기량을 고도각의 유계 역수로, 광학 두께를 지수 감쇠로 근사한다. 다중 산란·정확한 Mie 위상함수·분광 적분·유체역학·궤도역학을 계산하는 시뮬레이터가 아니다. 별은 구면상의 결정론적 점과 밝기 분포로 근사한다.

C. 가상 행성의 색·대기 밀도·먼지층, 이착륙 시간·유도 경로·카메라, 설계도의 부품 분리 간격은 작품적 설정이다. 화성 등 실재 행성의 정확한 재현이나 실제 우주선의 공학적 타당성을 주장하지 않는다.

계산 연결: 행성 키 → 대기 및 유도 프로파일 → 고도·수평 경로 → 탐사선 위치와 카메라 → 하늘·착륙 관찰 장면. 도킹 기준점은 마지막 프레임에서 정확하게 복원된다. 관객의 기존 수동/자동 전환과 비행 중 입력 잠금은 유지한다.

## 품질과 검증

| 품질 | 별 수 | 이주선 표시 선 상한 | 구조 |
|---|---:|---:|---|
| HIGH | 1944 | 6200 | 5계통·3투상·동일 비행 |
| MID | 1296 | 4600 | 동일 |
| LOW | 756 | 2700 | 동일, 기존 모바일 DPR 적용 |

별은 두 개의 정적 버퍼를 사용한다. 기존 프레임별 별 궤적 CPU 반복과 동적 버퍼 업로드를 제거했다. 대기에는 별도의 렌더 패스나 체적 노이즈를 추가하지 않았다.

- `npm run build`, `npm run verify`: 통과.
- `npm run harness`: WebGL2 경로의 셰이더 컴파일·카메라/차량 회귀 통과. GPU storage 계산 검증과 구분한다.
- `npm run blueprints`: 기존 차량 설계도 4개 화면/모션 조합 통과.
- `node tools/planet-visuals.mjs`: 세 품질 × 세 행성의 이륙/하강·착륙 기준점, 별 위치 불변·선 도형 0개, 이주선 주석 5개·내용 잘림 없음. `report.json`과 15개 PNG 참조. 단독 모델/하늘 검사는 지형을 제외한 시각 검사다.
- 기존 `npm run smoke:shortcut`은 독립 오프닝에서 제거된 `prologue === release` 상태를 기다리다 실패했다. 통과로 집계하지 않는다. 현재 페이지 구조를 검사하는 `node tools/planet-route.mjs`를 별도로 작성했다. 실제 이동 결과는 `route.json` 참조.
- 실물 iPhone/iPad의 터치, 장시간 발열·배터리, 프로젝터 암부 판독성은 이 자동 검사로 검증되지 않는다.

최종 시각 검토: 분해 투상도의 구조 분리, 데스크톱/390px 세로 라벨 간격, 세로 비행 프레임, 흰 궤도선과 별 궤적 제거를 직접 확인했다. RAW 색상과 GREEN 모니터를 구분하며 GREEN에서는 대기 색상이 녹색 명도로 변환된다.

최종 실제 재생 결과: `node tools/planet-route.mjs` 통과. Chrome WebGPU에서 P01 이륙 → P02 착륙·하차·시료 확보 → P02 이륙 → P03 착륙·하차와 도어 닫힘까지 완료했다. 콘솔/페이지 오류 0개. `route.json` 및 `live-*.png`에 기록했다. P03 도착 직후의 안정화 대기까지 검사했으며 이후 지질 탐사와 엔딩 전체를 재검사한 것은 아니다.
