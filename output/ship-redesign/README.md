# 이주선 리디자인 · FIRST DAWN

대상: `works/first_dawn/ships.js`, `works/first_dawn/main.js`, `works/first_dawn/camera.js`, `works/first_dawn/environment.js`, `works/first_dawn/surface.js`, `works/first_dawn/dev.html`. 독립 실행 배포본: 루트 `ending.html`, `works/terra_incognita/ending.html`, `dist/ending.html`.

첨부 스크린샷 5장의 낮고 넓은 쐐기형 실루엣, 높은 관측 함교, 하부 통과 때의 구조적 밀도를 기준으로 제작했다. 영화는 형태와 관측 경험의 참고이며 특정 영화의 우주선을 복제하지 않았다. 기존 5척, 60초 엔딩, 문구, 복귀 및 아카이브 흐름을 유지한다.

## 구조와 과학적 구분

A — 확립된 원리: 자유 비행 구간의 일정 속도 이동, 자세를 바꾸는 힘의 쌍, 표면을 통한 열 방출, 거주 압력 용기와 외부 구조의 분리. NASA의 열 제어·다층 단열·자세 제어 개요를 참고했다: https://science.nasa.gov/learn/basics-of-space-flight/chapter11-4/ , https://www.nasa.gov/reference/gateway-about/

B — 수치 근사: 위치를 해석적으로 계산하는 일정 속도 항해와 유한 시간 감속. 감속 구간 위치 다항식의 도함수는 1−3v²+2v³으로, 속도가 연속적으로 0에 도달한다. 자세는 작은 각도의 보간이며 제트의 실제 질량유량·관성텐서·추진제 소모는 계산하지 않는다. 중력장에 의한 실제 궤도 적분이 아니다.

C — 예술적 해석: 쐐기형 대형 차폐체, 높은 함교, 선단 간격, 60초 조우, 궤도상 열 방출판 전개 시점. 과학적으로 인증된 이주선 설계나 열·구조 해석 결과를 뜻하지 않는다.

## 시각 및 시간

세 개의 관측 시점과 두 번의 전환을 사용한다. 0–15초 원경, 15–35초 선체 측면/하부 근접, 35–60초 건조한 지표면에서 올려다보며 천천히 다가가는 시점. 각 컷은 0.75초씩 어두워지고 밝아져 먼 관측점 사이의 이동을 생략한다. 선단 위치 계산은 카메라로부터 독립되어 시점 전환이나 역방향 seek가 궤적에 영향을 주지 않는다.

마지막 카메라 높이는 절차적 지표 높이 + 1.7 단위다. 이는 장면에서 정한 눈높이이며 실제 화성의 좌표가 아니다. 지표 장면은 궤도상의 행성 메시를 대체하는 별도의 지역 분지다. 지형은 건조한 광물 행성의 예술적 해석으로, 실측 지형이나 대기 산란 시뮬레이션이 아니다. 바다, 흰 구름, 푸른 대기는 제거했다.

0–15초: 선단 접근과 빠른 확대. 15–35초: 측면을 병행 추적하며 더 확대. 35초: 지표면 컷. 38–44초: “우리는 이제 여기서 시작한다” 자막 등장. 35–60초: 앞쪽 120 단위, 옆쪽 45 단위 전진하며 가로 FOV 57→53.5도, 세로 70→67도로 완만하게 확대. 60초: 마지막 구도 유지. 기존 선단 애니메이션은 이 세 구간에 맞게 시간 재매핑하며 최종 선단 상태는 유지한다.

시간 입력 → 항해 위상 → 일정 속도/감속 위치 → 선체 위치와 자세 → 관측점별 원근 변화 → 열 제어 구조 노출 → 지표 관측 → 자막. 새 조작 패널은 추가하지 않았다.

## 품질

HIGH: 세분 차폐판, 정밀 곡면, DPR 최대 1.65, 2048 그림자.
MID: 차폐판과 곡면 간소화, DPR 최대 1.25, 1024 그림자.
LOW: 동일한 5척·실루엣·모듈·전개·궤적을 유지하고 차폐판/곡면 세분 수 축소, DPR 최대 1, 512 그림자.
세 단계 모두 지속적으로 프레임 시간이 높으면 내부 해상도를 단계적으로 낮춘다.

## 검증 범위

`npm run build:ending`, `npm run finale`: 세 품질 단계 렌더링, 일정 방향의 접근, 개별 속도, 방출판 완료, 재생/정지, 사운드 조작, 독립 file:// 실행 검증. 저장된 이미지를 직접 검토한다. 실제 휴대폰의 열·배터리, 전시장 프로젝터 검증은 포함되지 않는다.

내부 비평은 과학적 구분, 형태와 모델의 연결, 실루엣, 시간 구성, 기존 조작의 일관성, 품질 축소, 독립 실행성을 각각 검토한다. 설치 환경에 대한 확인을 브라우저 검증으로 대체하지 않는다.

2026-09-13 후속 검증: 세 관측 시점 순서, 지표면 눈높이, 마지막 전진 및 확대 카메라, 지표 장면 이전 자막 비표시, 정확한 자막 문자열, 카메라에 독립적인 선단 궤적을 검사한다.

## 가스층과 우주 배경 수정

행성의 세밀한 광물·계곡 무늬를 제거하고 낮은 공간 주파수의 가스층으로 대체했다. 가스층은 시간에 따라 느리게 이동하며, 표면의 기존 신호는 가스 아래에서 극히 약하게 남는다. 지표 장면은 세부 질감과 바위를 줄이고 거리 기반의 가스 소광으로 원경을 흐린다. 실제 화성 대기나 유체역학 해석이 아닌 예술적 가스 행성 표현이다.

우주 배경은 카메라 위치에 중심을 맞춘 천구에 크기·밝기·색온도가 다른 별과 옅은 별무리 띠를 배치한다. 관측점 이동에 따른 인위적인 별 시차를 없애고 카메라 회전에 따른 방향 변화만 유지한다. 별은 HIGH 6500 / MID 4200 / LOW 2000개이며 한 번의 포인트 드로로 렌더링한다. 지표면에서는 짙은 대기 때문에 별이 보이지 않는다. 두 번의 컷, 마지막 전진·확대, 정확한 자막은 유지한다.

전 시점의 접근 연출: 원경(0–15초)은 320 단위 전진과 FOV 6도 축소, 측면(15–35초)은 선체를 병행 추적하면서 상대 거리를 줄이고 FOV 5도 축소한다. 지표면(35–60초)은 승인된 접근·확대 폭을 25초에 맞춰 재생한다. 전체 길이 60초, 컷은 15초와 35초로 검증한다.

35초 이후의 하늘: 지표면 장면의 원경 하늘에 청록 회색과 보랏빛 회색의 낮은 채도 가스 띠가 10초에 걸쳐 나타난다. 느리게 이동하는 넓은 주름과 색 변화로 오로라 같은 인상을 만들며 실제 자기권·발광 스펙트럼 시뮬레이션은 아니다. 기존 하늘 셰이더에 통합하여 추가 렌더 패스 없이 모든 품질 단계에서 같은 동작을 유지한다. 선체와 지형이 하늘을 가리므로 효과가 전경 위에 겹치지 않는다.
