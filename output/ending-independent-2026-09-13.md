# 첫 번째 여명 — 독립 엔딩

## 최신 조형 수정

사용자 요청으로 작은 돌출 정비 블록, 갑판 장비 군집, 반복 배관과 중앙 기계열을 삭제했다. 큰 장갑판, 축소한 함교, 매립 모듈 한 쌍, 엔진과 방열판을 남겼다. 이주선 재질은 미세 텍스처·범프·금속 반사를 제거하고 3단계 음영의 MeshToonMaterial과 어두운 구조선으로 변경했다. 아래의 초기 PBR 설명은 이전 제작 단계의 기록이며, 현재 엔딩은 툰 렌더링이다. 다섯 척의 원근 경로와 anime.js 전개는 유지한다.

## 실행

`ending.html`을 직접 연다. 소스는 `works/first_dawn/`에 있으며, 임무의 `engine/`에는 의존하지 않는다. Three.js의 WebGL 렌더러와 anime.js를 HTML에 번들링한다. 모델과 표면 맵은 코드로 생성하므로 모델·텍스처·폰트를 외부에서 받지 않는다. 개발 화면은 `works/first_dawn/dev.html`이다.

전체 임무에서는 마지막 관측 완료 후 `ending.html`로 이동한다. 배포할 때 `dist/TERRA_INCOGNITA.html`, `dist/ending.html`, `dist/FIELD_ARCHIVE.html`을 함께 둔다. 독립 감상에는 `ending.html`만 필요하다. RETURN과 FIELD ARCHIVE는 전시의 인접 페이지로 가는 선택적 링크다.

## 조형과 시간

[Hobbes RnD](https://www.hobbes.work/projects/hobbes_rnd)의 시계 모델과 사용자가 제공한 화면에서 넓은 금속 모따기, 검은 매립면, 얇은 부품 경계를 참고했다. 사이트의 모델 파일을 복사하지 않고 이주선용 관측·정비 모듈, 방열판과 선체로 새로 모델링했다. 장갑판, 거주 구역, 정비 통로, 배관, 엔진 노즐은 실제 형상이며 금속 재질·거칠기·미세 요철·그림자를 적용했다. 와이어프레임은 구조 경계에만 낮은 불투명도로 남긴다.

카메라는 고정하고, 다섯 척의 평행 경로를 원근 투영한다. 깊이의 역수를 anime.js 타임라인으로 변화시켜 먼 곳에서는 작고 느리게, 가까워질수록 큰 선체가 드러나게 한다. 함선 크기는 시간에 따라 확대하지 않는다. 각각 다른 시작 시점과 소요 시간을 사용한다.

- 0–10초: 어둠과 행성 곡면. 선단은 원거리에서 출현한다.
- 10–60초: 실루엣과 편대 간격이 서서히 드러난다.
- 60–120초: 긴 모선의 장갑판과 거주 구역이 보인다. 91초부터 방열판이 함선별로 순차 전개된다.
- 120–150초: 가까운 모선이 프레임을 넘어서며 먼 네 척과 크기 대비를 이룬다.
- 150–180초: ‘우리는 이제, 여기서 시작한다.’와 기록 링크. 마지막에는 정지된 장면을 유지하며 REPLAY로 다시 시작한다.

소리는 사용자가 SOUND를 눌렀을 때만 시작한다. 사운드와 화면은 페이지 비활성화 시 일시정지한다.

## 원리의 구분

- 정확한 기하: 평행 경로의 공통 소실점, 카메라 원근 투영, 형상에 따른 표면 법선과 그림자.
- 실시간 근사: PBR 재질, 절차적 행성 표면, 제한된 해상도의 그림자와 환경 반사. 실제 천체·우주선의 공학 시뮬레이션은 아니다.
- 예술적 해석: 이주선의 설계와 접근 시간, 19회 개인전 `09-Bessel_bloom.html`의 방사형 간섭에서 응용한 세 정착 지역의 희미한 변화. 이 파동은 테라포밍 예측이 아니다.

## 품질 단계

HIGH는 작은 정비 부품까지 둥근 모서리로, MID/LOW는 작은 부품만 단순한 형상으로 처리한다. 주요 모따기 외장과 다섯 척의 구성, 접근·전개 시간은 동일하다. 프레임 시간이 길어지면 픽셀 비율을 단계적으로 낮춘다. 최대 그림자 맵은 2048 / 1024 / 512이며 반복 부품은 인스턴싱한다. 블룸과 다중 후처리를 사용하지 않는다.

자동 검사: `npm run finale`, `npm run verify`, `npm run smoke:finale`.
실물 모바일의 발열, 전시장 프로젝터와 스피커 청음은 별도 현장 확인이 필요하다.
