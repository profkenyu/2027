# Deep Space Resonance

기존 108초 영상·우주선·카메라·문구·링크를 유지하는 생성형 사운드.
구현: `audio.js`. `npm run build:ending`으로 Tone.js 15.1.22를 포함한
독립 HTML 3개와 개발용 `tone-runtime.js`를 재생성한다. CDN이나 음원 파일은 필요 없다.

## 모델과 구분

- 과학적 사실: sine/triangle의 스펙트럼, 필터 감쇠, 주기적 저주파 변조.
- 수치적 근사: 디지털 발진기와 합성 임펄스 응답을 이용한 컨볼루션 잔향.
- 예술적 해석: 진공에서 전달되는 실제 소리가 아니다. 카메라와 선체의 거리,
  영상 진행을 감각적 공명으로 변환한다. 물리적 거리 감쇠의 재현을 주장하지 않는다.

입력(첫 입력·음소거·재생·카메라 거리)
→ 거리 계수 1/(1+d/4500), smoothstep 엔벨로프, 균등분포 40–90초 간격
→ Tone 발진기/LFO/필터/딜레이/리버브
→ 영상 시간과 저역 이벤트 상태
→ 직접 저역과 먼 공명의 분리
→ 18–20초 등장과 18–19초 소거
→ 사운드 출력 → 기존 버튼으로 음소거 → 마지막 30Hz와 무음.

영상의 구도·색·조명·카메라 이동은 변경하지 않는다. 음향의 여백은 낮은 음량,
드문 이벤트, 분리된 등장 시간으로 만든다. 장식적 노이즈와 박자 패턴은 없다.

## 시간 구조

- 1초: 거의 무음. 첫 입력 전에는 오디오 문맥을 생성하지 않는다.
- 10초: 30/36/73Hz 저역이 서서히 등장.
- 30초: 173.2/617.3Hz의 먼 공명, 느린 필터와 음량 변조.
- 40–90초: 첫 sub event. 38→29Hz, 8초 등장·16초 소거.
  이후 이벤트 간격도 40–90초이며 90초 이후 새 이벤트는 금지한다.
- 66–84초: 고역 소거. 76–94초: 중역 소거. 82–101초: 드론 소거.
- 101–103초: 약 30Hz만 남음. 103–108초: 저역도 소거.
- 108초 이후(3분 포함): 무음 유지. 다시 재생하면 새 사건 일정을 만든다.

고역/중역 게이트를 잔향 뒤에 배치해 마지막 저역 구간으로 잔향이 새지 않게 한다.
최종 마스터 감쇠 이후 오디오 문맥을 정지한다. 마지막 무음 전환은
제어 갱신과 클릭 방지 램프 때문에 영상 종료보다 최대 약 80ms 늦을 수 있다.

## 성능과 수명

HIGH: 20초 리버브, 2.7/4.1초 딜레이, 보조 드론.
MID: 16초 리버브, 4.1초 딜레이.
LOW: 12초 리버브, 4.1초 딜레이.
모든 등급에 30Hz 바닥음, 드론, 먼 공명, sub event와 같은 소거 구조를 유지한다.
필터 LFO .031Hz, 음량 LFO .023Hz. 리버브는 등급당 하나만 사용한다.
오디오 제어값은 최대 약 12.5Hz로 갱신하고 음소거/숨김/종료 때 문맥을 정지한다.
재시작 때 이전 딜레이·잔향 노드를 폐기한다.

첫 화면 pointerdown 또는 키 입력에서 `Tone.start()`를 호출한다.
버튼은 자체 클릭으로 처리해 한 번 입력에 두 번 토글되지 않도록 한다.
사용자가 끈 뒤에는 화면을 눌러도 자동으로 다시 켜지지 않는다.
아이콘은 기존 푸터에 배치하고 aria-label, aria-pressed, 44px 터치 영역을 제공한다.

## 검증

`npm run finale`: 기존 3등급 화면·진행·재생·페이지 수명·단독 파일 회귀 검사.
`node tools/ending-audio.mjs`: 3등급 실제 신호, 모바일 터치 에뮬레이션,
잠금 해제, 이벤트 간격, 소거 순서, 재생, 음소거, 페이지 복귀, file:// 오디오.
결과는 `output/qa/ending-audio/`에 저장한다.
실물 iPhone/iPad Safari, 실제 스피커의 30Hz 재생, 전시장 음압과 장시간 발열은 별도 확인 대상이다.

API 참고: https://tonejs.github.io/docs/15.1.22/classes/LFO.html
